# Hardware and Software Baseline

## Keyboard

**Keychron Q1 Ultra 8K ANSI**

Known product capabilities from current Keychron documentation:

- ZMK firmware family
- Wired USB-C
- 2.4 GHz wireless
- Bluetooth 5.3
- Up to 8000 Hz polling over wired and 2.4 GHz
- 125 Hz over Bluetooth
- NKRO
- Rotary knob
- South-facing RGB
- macOS / Windows / Linux compatibility

## Primary environment

- Primary OS: Windows
- Primary game: World of Warcraft / WoW Forever
- Mouse: Logitech G502 Hero

## WoW mouse division of labor

The G502 already supplies ten convenient combat inputs:

- G8
- G7
- G5
- G4
- DPI Shift / sniper button
- Shift + each of the five buttons above

The keyboard should therefore emphasize movement, modifiers, utility, targeting and secondary abilities instead of trying to duplicate every primary combat action.
