# Macro Registry

Keep keyboard-level macros conservative, transparent and easy to audit.

## Rules

- Do not use keyboard macros to automate multi-action WoW combat behavior.
- Prefer WoW's own keybinding and macro system for gameplay actions.
- Keyboard macros are best used for OS, media, productivity and harmless utility tasks.
- Every configured macro should be recorded below.

## Factory macro state

The factory-reset Launcher screenshots show macro slots including `M0` through `M15`.

Do not assume the visible example content is part of the desired final profile. Capture the genuine Launcher macro export before treating any macro state as authoritative.
