# WoW profile design

## Goals

- Keep Layers 0/1 as Mac and Layers 2/3 as Windows.
- Preserve WASD movement in every profile.
- Use F13–F24 as clean virtual inputs for WoW.
- Preserve factory wireless shortcuts on Windows Layer 3 where practical.
- Make experimentation cheap: every profile is a complete importable keymap derived from factory.

## Profiles

### Conservative
Six underused physical controls become F13–F18. No layer behavior changes.

### Balanced
Caps Lock becomes a second momentary Layer 3 key. Caps+Q/E/R/F/Z/X supply F13–F18, while PgUp/PgDn/Home/Delete/knob/grave supply F19–F24. WASD remains pass-through while Caps is held.

### Aggressive
Caps Lock becomes a dedicated MMO modifier. Caps+Q/E/R/T/F/G/Z/X/C/V/B/N maps to F13–F24. WASD remains pass-through.

## Testing

1. Import one profile.
2. Use Launcher Key Test and/or Windows input testing to confirm F13–F24.
3. Bind the detected keys in WoW.
4. Play long enough to test movement + modifier combinations.
5. If the profile is annoying, import a less aggressive profile or the factory export.
