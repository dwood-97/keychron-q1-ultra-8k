# Windows WoW Export

Store genuine Keychron Launcher exports for the stable Windows/WoW profile here.

Expected design:

- Layer 0: Mac base, preserved
- Layer 1: Mac Fn, preserved
- Layer 2: Windows base + gaming-critical keys
- Layer 3: Windows Fn + secondary utility / optional extra gaming keycodes

Before declaring a revision stable, test it in World of Warcraft during normal movement, combat, chat and modifier use.
