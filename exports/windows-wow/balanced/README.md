# Balanced WoW profile

Purpose: keep normal Windows typing mostly intact while adding a real MMO modifier layer.

## Layer 2 changes

- Caps Lock → momentary Layer 3 (`Fn(3)`)
- PgUp → F19
- PgDn → F20
- Home → F21
- Delete → F22
- Knob press → F23
- Grave/Tilde (`) → F24

## Layer 3 additions while holding Caps

- Caps + Q → F13
- Caps + E → F14
- Caps + R → F15
- Caps + F → F16
- Caps + Z → F17
- Caps + X → F18

W, A, S and D remain pass-through on Layer 3 so movement continues to work while Caps is held. Factory wireless shortcuts on Fn+1 through Fn+4 are also preserved.

The Caps assignment uses keycode `21027`, copied from the factory Windows `Fn(3)` key rather than guessed.

This file is derived from the factory export. The exported `id`, `version`, and `MD5` metadata are intentionally preserved unchanged.
